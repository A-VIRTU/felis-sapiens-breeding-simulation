# Projekt Felis Sapiens - Simulační a Analytický Nástroj

Tato složka obsahuje dokumentaci simulačního softwaru a podpůrných vědeckých metodik určených pro expertní šlechtitelský projekt **Felis Sapiens**. Cílem celého programu je iterativně zvyšovat kognitivní (Feline IQ), sociální a adaptabilní schopnosti kočky domácí s ohledem na zachování zdraví a genetické variability.

## Obsah Dokumentace

1. **[Popis Projektu & Architektura (Závěry Simulací)](projekt-felis-sapiens.md)**
   Rozsáhlý konceptuální referenční dokument vysvětlující, *proč* software dělá to co dělá. K dispozici jsou zde sumarizace dosavadních běhů.
2. **[Standardizovaná Metodika Skórování Mláďat](metodika/skorovaci-dotaznik.md)**
   Extenzivní manuál definující relativní i absolutní sledování rozvoje mozku koťat a chovných zvířat. Aplikuje principy lidské kognitivní psychologie a teorie mysli do feline podoby.
3. **Vizuální Analýza Evoluce (HTML Grafy)**
   Složka `vizualizace/` obsahuje `index.html` s interaktivním datovým srovnáním šlechtitelských strategií.
